Glyph Atelier - 使い方

ZIPを展開し、index.htmlをブラウザで開きます。
1. 文字一覧で文字を選ぶか、入力して「追加」を押します。
2. ペンを選んで、白い画面を指・ペン・マウスでなぞります。直線はドラッグして引きます。
3. 太さはスライダーで変えます。「消す」は触れた線を丸ごと削除します。
4. プレビュー欄に文章を入力して確認し、OTFを書き出します。
5. 「保存」で編集可能なJSONをバックアップします。別の端末に移して「開く」で続きから作業できます。

端末のブラウザ内にも自動保存しますが、ブラウザのデータ削除で消えることがあるため、定期的に保存してください。下敷きはJSONには入りません。以前の輪郭式試作版のプロジェクトは読み込めません。下敷きの利用やフォントの配布は元フォントのライセンスを確認してください。

制限: 消しゴムは部分消去ではなく線単位です。線が多数重なった複雑なグリフや非常に長いストロークのOTFはアプリによって表示が異なる可能性があります。iPhone/iPadの実機では未検証です。opentype.js は同梱の LICENSE-opentype.txt を参照してください。

曲線・点の調整：曲線ツールで始点から終点までドラッグします。「点を調整」で線を選び、両端の紫色の点や、曲線のオレンジ色の点を動かせます。拡大・縮小ボタンで中央を拡大できます。グリッドの間隔は数値で指定できます。

円・楕円：「円・楕円」を選び、描きたい範囲の左上から右下へドラッグします。「点を調整」で円を選ぶと、対角の点を動かして大きさを変えられます。

初期文字：英大文字・小文字、数字、よく使う記号を用意しています。既存のプロジェクトでは「英数字・記号をまとめて追加」を押すと、作成済みの文字を残したまま不足分を追加できます。
